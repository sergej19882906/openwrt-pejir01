## 2. Релиз .47 — группы 1–3 (коммит `7931532`, PR #2)

12 файлов, **+653 / −5** (единый коммит PR #2). Серия патчей расширена до `0001..0078`.

### 2.1 LTE-сессия (патч 0074)
- `sync_apn` и `ecm_call` отправляли AT-команды GM510 с LF-терминатором — модем требует `\r` и молча игнорировал команды; ECM-сессия не поднималась. Все printf переведены на `\r`.
- Набор `AT+ZECMCALL` шёл под общим `AT_TIMEOUT=5`; теперь собственный `ECM_TIMEOUT` (30 с, переопределяется переменной окружения).

### 2.2 modeminfo (патч 0075)
- Сравнение `qmi_mode` исправлено с truthy `[ $qmi_mode ]` на строковое `[ "$qmi_mode" = "1" ]`.
- Удалены `kill -9 $(pgrep atinout)` и системный clean-up: modeminfo больше **не убивает чужие** процессы atinout (вкладку AT Command, параллельные modeminfo). Собственные вызовы ограничены `timeout 90`.

### 2.3 luci-app-atinout: wrapper (патч 0076)
- Обёртка `/usr/bin/luci-app-atinout` переводит порт в raw (`stty -F … 115200 raw -echo`) перед atinout; аргументы экранированы кавычками. Вкладка AT Command работает — «Доступ запрещён» устранён.

### 2.4 Меню LuCI и OTA (патч 0077)
- «3G/4G bands (PEJIR01)»: order 68 → 70 (was-конфликт с «Диагностикой USB, LTE и батарей»).
- `pejir-ota`: сравнение версий по полному четырёхкомпонентному ключу (v25.13.0-pejir01.5 против 25.12.6-pejir01.46), а не только по счётчику `.NN`.

### 2.5 Пин версий HOMEd (патч 0078)
- `zigbee-setup.sh`: фиксированные версии `homed-zigbee=3.16.4 homed-common=1.3.0 homed-web=2.25.1 homed-automation=2.9.0`; `HOMED_PIN=no` возвращает поведение «всё самое свежее».

### 2.6 build.sh — sha256-верификация
- ZIP с вендорскими блобами проверяется по `BLOBS_SHA256`, заводская прошивка — по `STOCK_SHA256`; несоответствие = падение сборки (escape hatch `PEJIR_ALLOW_BROKEN_BLOBS=1` / `PEJIR_ALLOW_BROKEN_STOCK=1`).

### 2.7 Тесты .47
- Новые: `tests/test-lte-terminators.sh`, `tests/test-atinout-wrapper.sh`, `tests/test-modeminfo.sh`.
