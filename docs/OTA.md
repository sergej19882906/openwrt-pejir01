# Обновление прошивки из LuCI (OTA)

В образе есть модуль `pejir-ota` — страница **Система → Firmware update (PEJIR01)**.
Она проверяет, есть ли новый релиз на GitHub, и ставит его **только по нажатию кнопки**.

Автоматического обновления нет: cron не настраивается, ничего не прошивается само.
Чтобы обновиться, нужно открыть страницу и нажать кнопку.

## Как это работает

1. **Check for updates** — скрипт `/usr/bin/pejir-ota check` спрашивает
   `https://api.github.com/repos/sergej19882906/openwrt-pejir01/releases/latest`
   и показывает установленную версию и последний релиз.
2. **Install update** — скрипт в фоне:
   - скачивает `*-squashfs-sysupgrade.bin` из релиза и файл `sha256sums`;
   - сверяет контрольную сумму образа (`sha256sum -c`);
   - проверяет образ через `sysupgrade --test`;
   - запускает `sysupgrade` — устройство перезагружается само.

Страница показывает журнал процесса и ждёт возвращения роутера в сеть.

## Настройка

`/etc/config/pejir_ota`:

| Параметр | Значение | Смысл |
|---|---|---|
| `repo` | `sergej19882906/openwrt-pejir01` | репозиторий с релизами |
| `asset` | `openwrt-ramips-mt7621-perenio_pejir01-34-BA-squashfs-sysupgrade.bin` | имя файла образа |
| `keep_settings` | `1` | сохранять настройки при прошивке (`sysupgrade` без `-n`) |

Версия образа хранится в `/usr/lib/pejir/version` — в ROM, а не в `/etc`:
при `sysupgrade` с сохранением настроек файлы `/etc` восстанавливаются из старой
системы, и маркер версии устарел бы. Значение подставляется на сборке из файла
`VERSION` в корне репозитория.

## Важно

- Обновляться можно **только между своими сборками**: `sysupgrade` не умеет ставить
  стоковую прошивку Perenio, и наоборот.
- **Настройки сохраняются** (`sysupgrade` без `-n`), поэтому Wi-Fi, WAN/LTE и
  extroot переживают обновление: конфиг переносится, флешка перемонтируется.
  Если в `/etc/config/pejir_ota` выставлено `keep_settings=0`, настройки и
  fstab extroot будут стёрты — тогда после обновления extroot придётся
  пересоздавать заново ([docs/POSTINSTALL.md](POSTINSTALL.md)).
- Сначала дождитесь, пока устройство переедет со стока (миграция `idata`, LTE),
  и только потом обновляйтесь.
- Первое обновление стоит обкатать через `initramfs-kernel.bin` по TFTP —
  он ничего не пишет в NAND ([docs/FLASH.md](FLASH.md)).
- Перед прошивкой сделайте бэкап разделов `Bootloader`, `factory`, `Config`, `idata`
  ([docs/FLASH.md](FLASH.md)) и не выключайте питание во время прошивки.
- Настройки сохраняются (`keep_settings=1`), поэтому после прошивки может понадобиться
  перезагрузить демоны вручную.

## Вручную (без LuCI)

```sh
# только проверить
pejir-ota check

# поставить обновление (в фоне, журнал в /tmp/pejir-ota.log)
pejir-ota install
pejir-ota status
```

## Почему не официальный attendedsysupgrade

`luci-app-attendedsysupgrade` не собирает образы для кастомных портов: сервер
`sysupgrade.openwrt.org` знает только устройства из своей базы, а `perenio_pejir01`
в ней не значится. Поэтому проверка обновлений сделана через GitHub Releases API.
